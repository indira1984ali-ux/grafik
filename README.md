# График дежурств

Веб-страница для составления графика дежурств: смены 8:00–17:00 и 10:00–19:00 (по 2 человека на поздней смене), отгулы, отпуска и больничные. Учитывает пятидневную 40-часовую неделю и государственные праздники РК.

Один файл `index.html`, без сборки и сервера. Данные хранятся в браузере (localStorage).

## Возможности
- Автоматическое распределение смен на месяц, поздние смены чередуются
- Отпуск, больничный, отгул диапазоном дат; ручная правка любой ячейки
- Предупреждения: больше одного человека в отгуле, меньше двух человек на смене 10–19
- Добавление и удаление сотрудников, загрузка списка из Excel (ФИО в первом столбце, см. `employees-template.xlsx`)
- Выгрузка графика месяца в Excel

## Публикация на GitHub Pages
1. Создайте репозиторий на github.com и загрузите все файлы из этой папки.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Праздничные переносы
Фиксированные праздники РК заложены в коде (массив `FIX` в `index.html`). Переносы и религиозные даты добавляются на странице или правкой `S.hol` по умолчанию.

## Примечание
Инструмент справочный. Кадровые решения сверяйте с Трудовым кодексом РК и юристом.
